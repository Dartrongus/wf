# Warframe Incarnon Tracker

[**Трекер Инкарнон Адаптеров**](https://dartrongus.github.io/wf/IncarnonTracker.html)

>Трекет установленных инкарнон адаптеров и ресурсов для их установки.


- Все галочки сохраняются в LocalStorage, есть возможность экспорта для переноса галочек на другое устройство/браузер



>A list of installed Incarnon adapters and the resources required to install them.


- All tick marks are saved in LocalStorage. There is an option to export them so they can be transferred to another device or browser
