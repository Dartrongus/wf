# Warframe Incarnon Tracker

[**Трекер Инкарнон Адаптеров / Incarnon Adapter Tracker**](https://dartrongus.github.io/wf/IncarnonTracker.html)

>Трекет установленных инкарнон адаптеров и ресурсов для их установки.


- Все галочки сохраняются в LocalStorage, есть возможность скопировать ссылку экспорта для переноса галочек на другое устройство/браузер



>A list of installed Incarnon adapters and the resources required to install them.


- All checkmarks are saved in LocalStorage; you can copy the export link to transfer the checkmarks to another device or browser
